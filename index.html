⚙️ Kurulum Gerekli

Uygulama henüz veritabanına bağlanmadı. Şu adımları izleyin:

  1. supabase.com adresinde ücretsiz hesap açın ve yeni proje oluşturun.
  2. Supabase panelinde SQL Editor'ü açın, projedeki db/setup.sql dosyasının içeriğini yapıştırıp Run deyin.
  3. Project Settings → API sayfasından Project URL ve anon public anahtarını kopyalayın.
  4. Bu projedeki js/config.js dosyasına yapıştırın.
  5. Sayfayı yenileyin.

Ayrıntılı anlatım için README.md dosyasına bakın.
